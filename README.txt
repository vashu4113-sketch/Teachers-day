Teachers' Day Invitation — Standalone Files

Included files:
- index.html       Page structure and content
- style.css        Layout, colors, responsive design, and animations
- script.js        Navigation, neural network effects, and RSVP behavior
- favicon.svg      Browser tab icon
- fonts/           Local DM Sans, DM Mono, and Instrument Serif font files

How to use:
1. Keep index.html, style.css, script.js, favicon.svg, and the fonts folder together.
2. Open index.html in any modern browser.
3. Replace [DATE], [TIME], and [VENUE] in index.html with your event details.

The RSVP form currently confirms submissions locally in the browser. It does not
send or store information on a server yet.
